# ADR 0001: единый источник пути конфига

Дата: 2026-11-23. Статус: принято.

## Контекст

`CONFIG` импортировался по значению в `config.py`, `sync.py` и `cli.py`.
`paths.set_config_path()` обходил `sys.modules` и патчил атрибуты по именам
модулей. Любой новый модуль с `from rb_tui.utils import CONFIG` молча не получал
флаг `--config`.

## Решение

Путь хранится только в `rb_tui.utils.CONFIG`. Чтение — через `utils.get_config()`,
изменение — через `utils.set_config()`. Потребители обращаются к атрибуту модуля
в момент вызова, а не к скопированному значению.

## Последствия

- `--config` и `RB_TUI_CONFIG` работают во всех модулях без списка исключений.
- Тесты патчат один объект (`utils.CONFIG`) вместо трёх.
- Удалён импорт по значению и цикл патчинга `sys.modules`.

## Альтернативы

Прокси-объект или `contextvar` — избыточны для однопоточного CLI.
