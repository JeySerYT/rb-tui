# ADR 0002: разделение CLI на модули

Дата: 2026-11-23. Статус: принято.

## Контекст

`cli.py` достиг ~770 строк: разбор аргументов, все команды, цикл проб,
интерактивное меню и вспомогательные сценарии в одном модуле. Это затрудняло
поиск и тестирование, а также создавало бы циклическую зависимость при попытке
вынести интерактив.

## Решение

- `cli.py` — только argparse и маршрутизация.
- `commands.py` — общие сценарии: пробы, бенчмарк, сравнение, скорость, fuzzy,
  watch, уведомление об обновлении. Не импортирует `cli`.
- `interactive.py` — главный экран и меню. Импортирует `commands`, но не `cli`.

Публичный контракт `rb-tui ...` не изменился.

## Последствия

- `cli.py` сократился примерно до 400 строк.
- Сценарии тестируются напрямую; для бюджетного сценария добавлены тесты.
- Нет циклических импортов: зависимости идут только вниз.

## Альтернативы

Оставить монолит — дешевле, но сохраняет проблему. Пакет `commands/` с
подпакетами — premature для текущего объёма кода.
