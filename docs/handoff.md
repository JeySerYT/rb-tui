## Риски и открытые вопросы

- Опубликованные теги не подписаны; 4 из 5 lightweight. Переподпись существующих
  тегов требует перезаписи remote — не делалось. Применять `git tag -s` для новых.
- В ruleset **не** включены обязательные одобрения, ревью CODEOWNERS и подписанные
  коммиты: в проекте один мейнтейнер, который является автором всех PR, поэтому
  эти правила заблокировали бы работу. Включать после появления второго
  ревьюера и настройки GPG/SSH-подписи.
- Social preview загружен в `assets/`, но факт загрузки в Settings надо проверить
  вручную — GitHub API это не открывает.
- Статус-чеки `test` и `install` станут обязательными после первого прогона CI
  на pushed-коммитах.
