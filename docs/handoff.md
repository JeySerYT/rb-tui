- Опубликованные теги не подписаны; 4 из 5 lightweight. Переподпись существующих
  тегов требует перезаписи remote — не делалось. Применять `git tag -s` для новых.
- Настройки репозитория (стратегии мержа, private reporting, ruleset) меняются
  отдельным этапом после локальных правок.
- Social preview загружен в `assets/`, но факт загрузки в Settings надо проверить
  вручную — GitHub API это не открывает.
