# Спека: исправление 8 находок и разбор `cli.main`

Статус: реализовано, проверено. Задача Kanso `RBT-16`.

## Цель

Сделать код технически корректнее и удобнее, не меняя публичный CLI-контракт:
устранить восемь подтверждённых проблем и разбить монолитный `cli.main()`.

## Границы

- Входит: правка JSONC, обработка битых метрик, учёт бюджета проб, поиск ключей
  в JSONC, источник пути конфига, отложенная инициализация, многопоточный
  дашборд, устойчивый разбор каталога, разделение модулей.
- Не входит: новые команды, новые форматы данных, изменение номеров версий,
  изменение GitHub-настроек (выполняется отдельным этапом).

## Критерии приёмки

1. Многострочная запись модели комментируется/удаляется без порчи JSONC.
2. Битый `metrics-history.json` не затирается, а откладывается в `.corrupt-*`.
3. При `ProbeThrottled` бюджет не списывается; успех фиксируется через `commit()`.
4. `"models": {` внутри комментария не влияет на поиск блока.
5. `--config` меняет путь во всех потребителях через один источник.
6. Импорт `rb_tui.utils` не создаёт каталоги и не меняет stdio.
7. Дашборд обслуживает клиентов параллельно.
8. Кривая запись каталога не роняет `--report`.
9. `cli.py` содержит только аргументы и маршрутизацию; сценарии и меню вынесены.

## Проверка

- 225 unittest, включая новые регрессионные тесты.
- semgrep: 0 находок, `compileall` OK, `git diff --check` OK.
- Smoke интерактивного режима: меню → выбор пункта → корректный выход.
- Runtime-репродукции всех восьми проблем до и после исправления.
