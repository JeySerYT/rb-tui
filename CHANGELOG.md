# Changelog

## 0.5.0-beta.2 (2026-11-22)

Автопроверка обновлений и установка для Windows одной командой.

**Обновления**

- При каждом запуске standalone-бинарник сам проверяет новую версию и пишет
  `↑ доступна новая версия`; результат кешируется на час, чтобы не упираться
  в лимит GitHub API (`RB_TUI_UPDATE_TTL`, `RB_TUI_NO_UPDATE_CHECK`)
- Ручные `--update-check` и `--update` всегда обращаются к GitHub напрямую,
  чтобы не показать устаревшую версию

**Установка**

- Windows: `irm .../install.ps1 | iex` — скачивает zip, проверяет sha256,
  распаковывает в `%LOCALAPPDATA%\rb-tui\bin` и добавляет папку в PATH
- В релиз вместе с `install.sh` публикуется `install.ps1`
- Заметки релиза берутся из `CHANGELOG.md`, а не из автогенерации коммитов

## 0.5.0-beta.1 (2026-11-22)

Честные цифры, полная история и дашборд v2.

**Защита API и корректность метрик**

- `--bench` (3 запроса), `--compare` (6) и `--speed` (1) теперь проверяют и
  списывают суточный бюджет через guard — лимит нельзя обойти другим флагом
- TPS считается по одной формуле везде: `tokens / total` для стриминговых
  замеров; терминал и дашборд больше не показывают разные числа
- `--bench` и `--compare` переведены на стриминг: TTFT, TTS и TPS вместо
  полного времени ответа под видом TTFT
- Метрики, конфиг, состояние каталога, теги и алерты пишутся атомарно
  (`tmp + os.replace`); обрезанный JSON при сбое больше не теряет историю
- Правки конфига целятся в `providers.reformboss.models`, а не в первый блок
  `models`; поддержаны оба варианта — `providers` и `provider`
- JSONC-парсер принимает висячие запятые перед `}` и `]`

**История и подмена модели**

- Полная история проб в `metrics-history.jsonl`; горячий хвост в
  `metrics-history.json` увеличен до 200 записей на модель
- `--trend <model>` — спарклайны TTFT/TTS/TPS по всей истории
- `--prune-metrics [N]` — ретеншен истории (по умолчанию 90 дней)
- Смена `system_fingerprint` отслеживается и всплывает в `--anomalies`,
  `--info`, дашборде и уведомлениях
- Новые аномалии: скачок TTS, падение TPS, абсолютный порог для TTFT
- Health score учитывает TPS

**CLI и уведомления**

- `--sort ttft|tps|rate|combined` для `--top`
- `--watch-interval`, `--watch-runs`, передача `--probe-budget` в watch
- `--test-notify` — диагностика desktop-уведомлений
- `--config-check` проверяет файл ключа, права 600, baseURL, пустые имена
  моделей и расхождение с последним каталогом
- Дедупликация алертов: 12 часов для аномалий, 24 часа для dead-моделей
- Webhook: корректные payload для Slack, Discord и generic, с повторами
- `--group-by-owner` использует реальный `owned_by` из каталога

**Самообновление**

- `--update` и `--update-check`: standalone-бинарник тянет последний релиз
  с GitHub, сверяет `sha256`, проверяет запуск нового файла и атомарно
  заменяет старый; источник можно переопределить через `RB_TUI_REPO`
- Автопроверка обновлений при каждом запуске: результат кешируется на час,
  чтобы не упираться в лимит GitHub API; `RB_TUI_NO_UPDATE_CHECK=1` отключает,
  `RB_TUI_UPDATE_TTL` меняет интервал
- На Windows замена применяется сразу после выхода из `rb-tui` — запущенный
  `.exe` нельзя перезаписать на месте
- Linux-бинарник сам находит системный CA-бандл и работает на Arch/CachyOS
- Сборки Linux x86_64 и Windows не требуют AVX
- Установка одной командой: `curl -fsSL .../install.sh | sh`

**Дашборд v2**

- Клик по модели открывает карточку: KPI, спарклайны TTFT/TTS/TPS,
  последние 12 проб, последняя ошибка и история fingerprint
- Фильтры по провайдеру и тегу, метки ошибок и смены fingerprint в таблице
- Экспорт CSV/JSON прямо из панели: `/export.csv`, `/export.json`
- `/health` отдаёт версию и uptime; `/api/model/<id>` — данные карточки
- Предупреждение при запуске на не-loopback хосте

**Поставка и тесты**

- Release-workflow запускается только после зелёных тестов
- CI: `compileall`, установка пакета и smoke-проверка `rb-tui --version`
- 92 теста: добавлены `test_config`, `test_sync`, `test_alerts`,
  `test_dashboard`, расширены метрики, guard и probe

- Автообновление панели каждые 30 секунд через `/api/view`; `/api/metrics` сохранён для совместимости
- Экспорт CSV и HTML: добавлены TTS и TPS
- `--stats`, `--info` и таблица теста показывают TTS и TPS
- Тестов стало 52

## 0.2.0-beta.2 (2026-11-22)

Бережное тестирование: инструмент больше не выглядит как массовый опрос API.

- Новый модуль `guard.py`: бюджет проб, ротация, суточный лимит, cooldown
- Пробы только по моделям из живого каталога; пропавшие не зондируются
- Порция 10 моделей за прогон (`--probe-budget`), ротация «кого давно не проверяли»
- Пауза 3с + случайный разброс между запросами
- Суточный лимит 80 проб
- При `catalog_probe_detected` / `token_concurrency_limit` прогон сразу
  останавливается, инструмент уходит в 6-часовой cooldown; ложных `dead` больше нет
- `--probe-model <model>` — проверить одну модель
- `--probe-reset` — снять паузу проб
- Ошибки теперь сохраняются в метриках (`msg`) и видны в таблице теста
- Исправлена установка: корректный build-backend и чтение версии после `pip install`
- Исправлены `--json` / `--export-html` / `--export-csv` без аргумента (вывод в stdout)
- Дашборд по умолчанию слушает `127.0.0.1`; понятное сообщение при занятом порту
- `--test` в интерактивном терминале действительно запускает тест, а не меню
